# SurfaceGuard AI: Industrial Surface Anomaly Segmentation

## Project Overview

This project aims to develop a computer vision system for detecting and segmenting surface anomalies in industrial inspection images.

The model will identify different categories of defects and localize anomalous regions at the pixel level using image segmentation techniques.
